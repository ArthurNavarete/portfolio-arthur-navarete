# Portfólio de Arthur Navarete

Site pessoal em português do Brasil, feito com HTML, CSS e JavaScript. Vite gera os arquivos estáticos para hospedagem.

## Desenvolvimento

```bash
npm ci
npm run dev
```

## Publicação na Hostinger

Importe este repositório como aplicativo web de frontend/Vite. Use a branch `main`, Node.js 22 ou 24, o comando `npm run build` e a pasta de saída `dist`. Não há comando de inicialização, API ou variáveis de ambiente.

Para verificar o build localmente:

```bash
npm run build
npm run preview
```

Os links de contato levam diretamente ao e-mail, LinkedIn e GitHub. O site não contém formulário nem coleta de dados.
